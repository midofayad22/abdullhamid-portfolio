04 المهارات

ما أبنيه.

المهارات التي أستخدمها فعليًا في مشاريعي الحالية، من بناء الواجهات إلى التعامل مع البيانات والتطبيقات المتجاوبة.

  1. 01

    Front-End

    واجهات مدروسة في كل تفصيلة.

    بناء واجهات متجاوبة باستخدام HTML وCSS وJavaScript، مع اهتمام بالـTypography والـSpacing والتفاعل وسهولة الاستخدام.

    • HTML
    • CSS
    • JavaScript
    • واجهات متجاوبة
  2. 02

    تطبيقات React

    بناء واجهات قائمة على المكوّنات باستخدام React وTypeScript، مع تنظيم الـroutes والـUI.

  3. 03

    بيانات حقيقية

    التعامل مع Supabase والبيانات الحقيقية داخل تطبيقات فعلية.

  4. 04

    تجارب متجاوبة

    بناء تجربة متناسقة للهاتف والتابلت والـDesktop مع الاهتمام بسلوك الواجهة.

  5. 05

    الأداء والجودة

    اهتمام بالأداء وسرعة التحميل وSEO وإمكانية الوصول (Accessibility) داخل المشاريع.
